## Overview

This repository contains the computational pipeline accompanying the manuscript:

> *Spanning-Tree Thermostatistics of Protein Allostery: An Exact Kirchhoff Framework with Application to Oncogenic KRAS*

The framework treats protein allostery as a statistical mechanical problem over the spanning-tree ensemble of the residue contact network. Each spanning tree is a topological microstate encoding one cycle-free realization of the global communication network. The canonical partition function is evaluated exactly via Kirchhoff's Matrix-Tree Theorem, yielding global and channel-specific thermodynamic state functions (free energy, internal energy, entropy, heat capacity) without approximation.

We apply the framework to the oncogenic **G12D** point mutation in **KRAS**, comparing wild-type (PDB: [6GOD](https://www.rcsb.org/structure/6GOD)) and mutant (PDB: [6GOF](https://www.rcsb.org/structure/6GOF)) structures.

### Key findings

- The G12D mutation reduces global heat capacity by **27.3%** while leaving mean energy and entropy essentially unchanged (<0.5% shift).
- Channel-level heat capacities are **near-invariant** (|ΔC| < 1.5%), but their energetic, topological, and cross-coupling components undergo large compensatory shifts.
- Residue-level allosteric importance is substantially redistributed: Q61 gains +22.7% in the pre-Switch II channel; A155/F156 gain +29.1%/+35.5% in the inter-lobe bridge.
- The mutation does not destroy allosteric communication — it **captures** it, rerouting information flow through residues that stabilize the GTP-bound, catalytically impaired state.

## Scripts — Description and Run Order

The scripts are numbered by their logical execution order. Each is self-contained and can be run independently, but the recommended workflow is:

| # | Script | Purpose | Reproduces |
|---|--------|---------|------------|
| 1 | `1_channel_analysis.py` | Full pipeline: builds Cα graphs, computes convergence r(L) for all five channels, computes channel Cv, and generates the convergence figure. | **Table 2**, **Figure 2** |
| 2 | `2_compute_cv_table.py` | Standalone Cv computation with log-sum-exp stabilization. Writes formatted `.txt` and `.csv` tables. | **Table 2** (cross-check) |
| 3 | `3_cv_decomposition.py` | Decomposes each channel Cv into energetic (C_E), topological (C_T), and cross-coupling (C_X) components. | **Table 2** (ΔC_E, ΔC_T, ΔC_X columns) |
| 4 | `4_participation_ratio.py` | Computes residue-level participation ratio PR = 1/Σpᵢ² for each channel. Lightweight (numpy only, Colab-ready). | Supporting analysis |
| 5 | `5_generate_ensemble.py` | Enumerates the full path ensemble for a single (source, target) pair and writes all paths with their Burton–Pemantle probabilities. | Input for script 6 |
| 6 | `6_jsd_rewiring.py` | Computes Jensen–Shannon divergence between WT and G12D ensembles and produces the residue-level rewiring table. | **Table 3** |
| 7 | `7_convergence_single.py` | Interactive single-channel convergence diagnostic. Useful for exploring channels beyond the five predefined ones. | **Figure 2** (single panel) |

### Dependency between scripts

```
5_generate_ensemble.py  ──►  6_jsd_rewiring.py
       (WT + G12D ensemble files feed into JSD analysis)

All other scripts are fully independent.
```

## Quick Start — Reproducing the Paper

### 1. Global thermodynamics (Table 1)

Global properties (⟨E⟩, S, C) are computed internally by scripts 1 and 2 as part of the Kirchhoff partition function evaluation.

### 2. Channel heat capacity table (Table 2)

```bash
cd src/
python 1_channel_analysis.py
# Enter: ../data/6GOD.pdb, ../data/6GOF.pdb, cutoff=7.8, kT=1.0, max_L=9
```

This produces:
- `convergence_rL.png` → **Figure 2**
- `cv_comparison_table.txt` → **Table 2**

### 3. Cv decomposition (Table 2, ΔC_E/ΔC_T/ΔC_X columns)

```bash
python 3_cv_decomposition.py
# Upload 6GOD.pdb and 6GOF.pdb when prompted (or place in working directory)
```

### 4. Residue rewiring analysis (Table 3)

```bash
# Step 1: Generate ensembles
python 5_generate_ensemble.py   # Run for 6GOD.pdb (WT)
python 5_generate_ensemble.py   # Run for 6GOF.pdb (G12D)

# Step 2: Compare
python 6_jsd_rewiring.py
# Provide the two ensemble files from step 1
```

## Method Summary

### Graph representation
The protein is represented as a weighted graph G(V, E) where vertices are Cα atoms and edges connect residues within a cutoff distance (default: 7.8 Å). Edge weights follow a Boltzmann form: w_ij = exp(−d_ij / kT).

### Partition function
The global partition function Z is the sum over all spanning trees, computed exactly as det(L̃_w) via Kirchhoff's Matrix-Tree Theorem.

### Channel analysis
Allosteric channels between residue pairs are defined as sub-ensembles of spanning trees containing a unique simple path between endpoints. Path probabilities are computed exactly using the **Burton–Pemantle theorem** via the edge-response matrix constructed from the Moore–Penrose pseudoinverse of the graph Laplacian.

### Thermodynamic decomposition
Channel heat capacity decomposes as: **C_AB = C_E + C_T + C_X**, where C_E captures energetic (distance) variance, C_T captures topological (spanning-tree degeneracy) variance, and C_X captures their cross-correlation.

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `cutoff` | 7.8 Å | Cα contact distance threshold |
| `kT` | 1.0 (reduced units) | Effective temperature |
